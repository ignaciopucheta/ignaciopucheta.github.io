# Portfólio Pessoal — Ignácio Pucheta

Site pessoal desenvolvido, mantido e atualizado por mim, reunindo minha trajetória profissional, formação e experiências como Contador especializado em Departamento Pessoal, RH e consultoria migratória Mercosul.

🔗 **Acesse ao vivo:** [ignaciopucheta.github.io](https://ignaciopucheta.github.io/)

## Sobre o Projeto

Este repositório contém o código-fonte do meu portfólio, construído com **HTML5, CSS3 e JavaScript puro** (sem frameworks), hospedado no GitHub Pages. Além de apresentar meu currículo, o site é usado como espaço de prática e demonstração de habilidades de front-end.

### Funcionalidades

- 🌗 **Modo claro/escuro**, com preferências de cor persistidas via CSS puro
- 💬 **Modal de boas-vindas** com tela de feedback integrada, enviando mensagens diretamente para meu e-mail via [Formspree](https://formspree.io/)
- 📱 **Contato direto pelo WhatsApp**, com link inteligente (`wa.me`)
- 📊 **Analytics de privacidade em primeiro lugar**, via [Umami](https://umami.is/), sem cookies
- 🔍 **SEO otimizado**, com meta tags, Open Graph, Twitter Card, `sitemap.xml` e `robots.txt`
- 🖼️ **Favicon completo** (todos os tamanhos, incluindo Apple Touch Icon e ícones Android)
- 📱 Layout responsivo para desktop, tablet e celular

## Como Rodar Localmente

Como é um site estático, basta clonar o repositório e abrir o `index.html` no navegador:

```bash
git clone https://github.com/ignaciopucheta/ignaciopucheta.github.io.git
cd ignaciopucheta.github.io
```

Ou usar uma extensão como *Live Server* (VS Code) para recarregamento automático durante o desenvolvimento.
